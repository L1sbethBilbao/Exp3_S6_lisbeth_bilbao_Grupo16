IMG-09 | Fallback cuando ms-cuentas no esta disponible
------------------------------------------------------

  Respuesta Postman (lista vacia por fallback) y/o log del BFF con "FALLBACK"

IMG-15 | OAuth2 client_credentials + JWT (como ejemplo del profesor)
--------------------------------------------------------------------
Paso 1 - obtener token (Postman):
  POST http://localhost:9000/oauth2/token
  Authorization: Basic Auth
    Username: bancoxyz-bff-client
    Password: secret123
  Body -> x-www-form-urlencoded:
    grant_type = client_credentials
    scope      = cuentas.read
Que debe verse:
  access_token (JWT), token_type bearer

Paso 2 - usar el token:
  GET http://localhost:8090/api/oauth2/cuentas
  Authorization: Bearer Token -> pega el access_token
Que debe verse:
  200 con cuentas + subject/scope del JWT

Captura sugerida: una del token y otra del GET con Bearer.
Texto sugerido:
  "Flujo OAuth2 client_credentials (maquina a maquina): el auth-server
   emite JWT y ms-cuentas (Resource Server) valida el token y el scope
   cuentas.read, tal como en el ejemplo de clase."

  sin Bearer token

  401 Unauthorized
